# Code of Conduct

[简体中文](CODE_OF_CONDUCT.md) | **English**

aiverywhere wants participants to discuss problems on the merits without fear of attack or harassment.

## Expected behavior

- Respect different levels of experience, languages, platforms, and tool choices.
- Discuss concrete behavior, evidence, and tradeoffs; do not speculate about motives.
- Accept maintainers' decisions about scope, design, and release cadence.
- Use synthetic material in public channels; keep real credentials and user data local.
- Correct your own mistakes and leave room for others to correct theirs.

## Unacceptable behavior

- Insults, threats, discrimination, harassment, or sustained personal attacks.
- Publishing another person's identity, accounts, logs, or private conversations without permission.
- Pasting secrets, cookies, WeChat content, or other sensitive data into issues, PRs, or discussions.
- Repeatedly ignoring the scope set by maintainers, or intentionally consuming review or runtime resources.

## Scope

This code applies to issues, pull requests, discussions, reviews, and public settings where someone represents the project.

## Enforcement

If a problem occurs, contact the repository maintainer privately through their GitHub profile and include verifiable context. Maintainers may ask for the behavior to stop, remove content, close discussions, or restrict participation. For security vulnerabilities, use the [security policy](SECURITY.en.md) instead of public disclosure.

This code is based on [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
