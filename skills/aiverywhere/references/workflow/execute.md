# execute · 执行与验证

契约版本 1

## 职责与触发

需要采取行动、生成产物或查证事实时调用。只做完成目标所需的最小行动。

## 输入与输出

输入：目标、权限、已有证据、必记项。

输出：产物或行动结果、证据位置、验证结果、未解决问题。

## 做法

1. 使用宿主原生工具或当前环境获准的命令，不把安装 CLI 当成前提。
2. 对产物做与目标相符的检查；写入后核对实际内容，而不是只相信命令退出码。
3. 当前事实从官方或一手页面核实；搜索结果只是线索。
4. 只有 1–2 个独立、可并行的子目标才委派 worker；需要理解意图、判断可信度或提交长期记忆的工作留在主任务。
5. worker 只能提出候选记忆，主 agent 核验后统一写回项目。
6. 取消时停止新动作；已经完成的原子写入保留回执。

## 示例

应触发：修改文件后读取结果并核对差异。

可跳过：只需要解释概念，不需要工具。

## 失败处理

区分权限、网络、超时、格式、冲突和结果未知。部分完成时交回已完成产物和具体未完成项，不把“已执行”包装成“已验证”。
