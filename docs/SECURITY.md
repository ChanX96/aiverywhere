# 安全策略

**简体中文** | [English](SECURITY.en.md)

## 支持范围

安全修复面向最新发布版本。当前为 `0.1.x`。

## 私下报告

请通过 [GitHub 私有安全公告](https://github.com/ChanX96/aiverywhere/security/advisories/new) 报告漏洞。不要在公开 Issue 中粘贴凭据、个人微信内容、`data/` 下的用户资料或可识别的运行日志。

报告请包含：受影响版本与平台、入口（安装器、CLI、本地工作台、MCP、微信网关）、复现条件、实际影响，以及已做的脱敏处理。维护者会确认收到并尽力在修复发布后公开说明。

## 本项目的安全边界

- `config.json` 可能包含模型凭据，以 `0600` 原子写入。不要提交、截图或转发 `config.json` 或 `data/`。
- 本地工作台只绑定 `127.0.0.1`，使用页面会话标识和同源检查，不提供远程访问。
- 安装器不请求 `sudo`，不修改 shell 启动文件，不注册系统服务。`--cli` 仅在 `<bin-dir>/aiverywhere` 创建命令链接；已有非本安装器的文件不会被覆盖。
- `install.sh` 从配置的仓库获取源码并交给 `pip` 构建。对来源有疑虑时，先下载并审阅脚本，再用 `--source` 指向已核对的本地源码或发行包。
- 模型端点、MCP 服务、原生执行器和微信网关由使用者配置；它们的权限、日志与凭据由各自环境负责。运行任务前确认授权范围。
- 不给维护者发送真实用户数据。复现问题时使用合成资料，并清理日志中的路径、账号和凭据。
