# 行为准则

**简体中文** | [English](CODE_OF_CONDUCT.en.md)

aiverywhere 希望参与者能就事论事地讨论问题，而不必担心被攻击或骚扰。

## 期望的行为

- 尊重不同经验、语言、平台和工具选择。
- 讨论具体行为、证据和取舍，不揣测他人动机。
- 接受维护者对范围、设计和发布节奏的决定。
- 在公开渠道使用合成资料；真实凭据和用户数据只放在本地。
- 主动纠正自己的错误，并给他人留出修正空间。

## 不接受的行为

- 侮辱、威胁、歧视、骚扰或持续的人身攻击。
- 未经允许公开他人的身份、账号、日志或私密对话。
- 在 Issue、PR 或讨论中粘贴密钥、Cookie、微信内容等敏感数据。
- 反复无视维护者划定的范围，或恶意消耗评审与运行资源。

## 适用范围

本准则适用于仓库的 Issue、Pull Request、讨论、评审，以及代表项目参与的公开场合。

## 执行

遇到问题时，通过仓库维护者的 GitHub 资料私下联系，并附上可核查的上下文。维护者可以要求停止相关行为、删除内容、关闭讨论或限制参与。涉及安全漏洞时改用[安全策略](SECURITY.md)，不要在公开渠道披露。

本准则参考 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)。
