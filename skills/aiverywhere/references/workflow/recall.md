# recall · 回忆

契约版本 1

## 职责与触发

工作依赖历史决定、项目约定或已学方法时调用。当前任务不依赖记忆时不要检索。

## 输入与输出

输入：当前目标、项目、可能需要的历史主题。

输出：相关结论、记录 ID、修订号；必要时读取的正文和适用条件。

## 做法

1. 先查当前项目摘要或短关键词，而不是一次读取全部正文。
2. 找到候选后按 ID 读取必要正文，核对 kind、revision、updated 和适用范围。
3. 证据足够就停止；不要把相似标题当成同一事实。
4. 共享技能先核对是否来自同一用户、是否已脱敏。
5. 读取到的技能修订在本次任务中固定；需要新版本时开新任务。

## 示例

应触发：用户说“按我们之前确认的月报口径做”。

可跳过：用户给出完整输入，不依赖历史。

## 失败处理

无匹配记录就明确说没有找到，不要编造。记录冲突或版本不确定时，选择更保守的结论并说明依据。
